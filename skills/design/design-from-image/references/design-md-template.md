# design.md 骨架与填写说明

下面方框里的内容就是 `design.md` 的全文结构。方括号是占位符，替换成实际值；用不到的章节整节删掉，不要留空标题。

填写要求：

- 每条令牌、每条规则后面跟来源标注（`观察到` / `裁定` / `推断`），只有「缺口」章节里的条目不加。
- 令牌名直接写成 CSS 变量名，实现时原样照抄，所以名字要能直接用。
- 有意留空的地方写进「缺口」章节，明说不知道。留白比编造有价值。

## 附录 A：令牌命名固定词汇

用这些名字，不要另造同义词，否则跨会话会漂移。左列是需要表达的东西，右列是它的令牌名。

| 用途 | 令牌 |
|---|---|
| 页面底色 / 卡片面 | `--color-bg` / `--color-surface` |
| 文字三级 | `--color-text` / `--color-text-muted` / `--color-text-subtle` |
| 边框与分隔线 | `--color-border` |
| 主操作 / 次操作 | `--color-primary` / `--color-secondary` |
| 语义 | `--color-success` / `--color-warning` / `--color-danger` / `--color-info` |
| 间距 | `--space-1` 起（1 就是基准单位，不是 1px） |
| 圆角 | `--radius-sm` / `--radius-md` / `--radius-lg` / `--radius-full` |
| 阴影 | `--shadow-sm` / `--shadow-md` / `--shadow-lg` |
| 时长 | `--duration-fast` / `--duration-base` |
| 缓动 | `--ease-out` / `--ease-in-out` |

## 附录 B：最常见的四个错误

1. **把每个控件量到的值都单独记一条令牌**，不做归纳。终点是系统，不是测量记录。相近的值要合并。
2. **用描述外观的名字**（`--blue-500`、`--gray-2`）。换个色相名字就错了，用用途命名。
3. **图上没画的状态写得像真的一样**。hover 的色值从哪来的？没有出处就要标推断，推不出来就进缺口。
4. **记了颜色不记用途**。`#2563eb` 没用，「主操作、选中态」才有用。
