# 提取方法

每类令牌怎么从一张图里读出来，读不准时怎么标。

## 输入类型

| 类型 | 特征 | 处理 |
|---|---|---|
| 控件展示板 | 多个控件平铺排列，背景干净 | 最理想，逐个控件提取 |
| App 截图 | 完整手机屏，含状态栏与导航 | 忽略状态栏与页面背景，只取控件 |
| 网页截图 | 含浏览器外框或整页长图 | 先切出控件区域；长图按模块分区 |
| 设计稿导出 | 带标注线、红框、多画板 | 分画板提取，忽略标注层 |
| 拍屏 | 摩尔纹、透视变形、反光 | 颜色只作参考，明确告诉用户这张图的精度不可靠，建议换原图 |

图里没有 UI 控件（只有 logo、插画、照片）就停下，告诉用户这张图提不出设计系统。

## 颜色

按角色取，不按在图上出现的顺序取。

1. **背景**：找出所有不同的底色，按深浅编号（暗色模式反着来）。
2. **文字**：主文字、次文字、弱化或占位文字，以及任何有色文字。
3. **交互**：主按钮、次要按钮、链接、开关、选中态。主操作与次操作要分开。
4. **语义**：成功、警告、危险、信息。图里没有就**不要编**，留给缺口提问。
5. **强调与品牌**：主品牌色、次强调色。
6. **边框与分隔线**：常常很淡，用 `scan` 以 `--tolerance 3` 扫。半透明的记下透明度估计。

取色纪律：

- 用 `sample` 或 `palette`，不要目测。同色系的两个点拿不准是不是一个色，`sample` 出来比 hex：通道差都在 2 以内按一个色处理，差得多就是两个色。
- 采样点落在纯色区域中心，离边框至少 2px，避开文字抗锯齿与阴影渐变。
- `--avg 3` 能压制 JPEG 噪点，但**跨在边缘上的点不能用它**，均值会把背景色掺进来。边缘附近一律单像素取样。
- 同一颜色在多个控件出现时记下全部出处，归纳时用它判断这是令牌还是偶然。

## 排版

1. **从大到小扫一遍**，把每段文字按视觉层级分组。
2. **字体族**：认得出来就写具体名字，认不出写「疑似 X 或同类几何无衬线」，并给置信度（高 / 中 / 低）。
3. **字号**：以正文为锚，其他用比例或估算像素表示。所有像素值前面加 `~`，除非图上有明确标注。
4. **字重**：记下出现的不同字重，通常是 400 到 700 里的几个。
5. **行高**：正文与标题分别估，标题通常比正文紧。
6. **字距**：注意标题是否收紧、标签是否放宽、全大写是否额外加字距。

换算实际字号：如果知道图的真实渲染宽度（App 截图通常是 390pt 或 393pt 宽），用 `scan` 扫出文字块高度的像素数，按 `实际字号 = 像素高度 / 图宽 * 真实宽` 换算。换算过的值比 `~` 估算可信，标注成「观察到（按图宽 N 换算）」。

## 间距与尺寸

1. **先找基准单位**：看最小的重复间距，常见 4px 与 8px。查图标与文字的间隙、输入框内边距、紧邻元素对。
2. **再量四级**：控件内部（按钮、卡片、输入框、列表行的内边距）、同级元素之间（按钮组、表单字段、列表项）、区块之间、页面边距。
3. **量法**：用 `scan` 沿垂直或水平线扫过一段，读各分段的像素长度。
4. 记下间距是严格成刻度还是随手定的。不严格就照实说，不要硬凑成一个漂亮刻度。

## 形状与深度

- **圆角**：用 `scan` 斜着扫过角部，读过渡段的像素长度估半径；也可用 `sample` 逐点比对边缘。分档记录（小 / 中 / 大 / 全圆），不记精确半径。
- **阴影**：记方向、模糊量级、是否带颜色。阴影色常是主色的暗化版，或黑色低透明度。
- **边框**：宽度、颜色、是否只出现在某几条边。

## 控件

对 Step 1 清点到的每个控件记录：结构（几层、各层放什么）、尺寸（高、内边距、元素间距）、各元素颜色与字体、圆角、阴影、边框。

图里通常只画了默认态。hover、focus、active、disabled、loading、错误态不在图里，**不要照着“通常长什么样”编**，留给缺口提问。

图里没有、但设计系统通常有的控件（比如只有默认按钮没有危险按钮）：**不要补**。列进「缺口」章节，要用的时候再说。补出来的控件不是提取，是发明。

## 边界情况

- **图有透视或压缩变形**：只提取相对关系，标注绝对像素不可信。
- **分辨率太低**（控件小于 40px）：字号与间距标为估算，颜色仍然可信。
- **多画板设计稿**：按画板分别提取再归纳；画板之间冲突时问用户以哪个为准。
- **暗色模式图**：颜色角色反转（最浅的是背景而不是前景），语义色通常要调亮，标注这是暗色下的值。
- **图是深色底上的浅色控件**：别把浅色当背景处理，先判断哪一层是页面底。
