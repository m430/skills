# 记待规划需求

把当前对话里冒出来的想法提炼成一条**待规划需求**，写进 `sprints/backlog/`。backlog 是不归属任何迭代的需求池，作用是帮你记住要做哪些事，日后由 `/plan-sprint` 挑进迭代。

**不要访谈。** 从已经谈过的内容里提炼；谈得不够就只写写得出来的字段，其余留空。

## 流程

1. 提炼一条需求，起一个短标题。对话里有多个独立想法时，一条一个文件。
2. 写进 `sprints/backlog/<slug>.md`，`<slug>` 用英文短横线连写（例如 `report-export.md`）。目录不存在就创建。
3. 同名文件已存在时**更新它**，不要另起一份。
4. 告诉用户记下了什么、放在哪。

## 模板

<backlog-template>

# 标题

**想要什么：** 一句话，从用户视角描述

**为什么：** 它解决什么问题、带来什么收益

**验收意图：** 什么算做成（人话，不是测试用例）

**备注：** 讨论里冒出来的其他信息

</backlog-template>

backlog 条目**不编号**：它还没排进任何迭代，序号留给排期后的 story 文件。
